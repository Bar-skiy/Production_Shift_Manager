# Название проекта

## Production Shift Manager — Управление сотрудниками и производственными командами

Веб-приложение для управления производственными командами и сотрудниками. Позволяет формировать сменные группы, распределять сотрудников, отслеживать состав команд, а также выполнять основные операции с данными через удобный web-интерфейс.

# Используемые технологии

Java  
Spring MVC  
Maven  
PostgreSQL  
HTML  
Thymeleaf  
Bean Validation API  
SQL

# Краткое описание

Система позволяет создавать команды, назначать сотрудников, изменять состав групп, а также управлять информацией о персонале. Предусмотрены механизмы открепления и переназначения сотрудников, валидации данных и просмотра состояния как отдельных команд, так и каждого участника.

Реализован удобный интерфейс с навигацией по спискам и детальными карточками. Все основные операции — добавление, редактирование, удаление — доступны как для сотрудников, так и для команд. Интеграция с базой данных и встроенная проверка данных обеспечивают надёжность и корректность ввода.

# Возможности

- Управление списком сотрудников и команд
- Назначение и открепление сотрудников от команд
- Отображение состояния каждого участника и команды
- Валидация данных при вводе
- Отражение структуры в интерфейсе: списки, карточки, формы
- Поддержка различных состояний: свободен, назначен, без команды
- Возможность масштабирования под задачи HR, управления сменами, распределения ресурсов

Приложение может использоваться как основа для корпоративной системы управления персоналом.
